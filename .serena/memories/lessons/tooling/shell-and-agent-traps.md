# Công cụ & shell trên Mac — bẫy của chính máy này

- Bash tool chạy zsh macOS: biến không nháy KHÔNG word-split (`J="-b jar -H origin:x"; curl $J` thành MỘT đối số → mọi request 401 giả; `pnpm exec eslint $FILES` nhiều dòng → `ENAMETOOLONG`); `echo ======` lỗi (`=word` expansion) → quote chuỗi bắt đầu bằng `=`. **How**: viết đối số tường minh, `${=VAR}`/`xargs -0`, hoặc script `bash`; macOS không có `timeout`; thấy 401/"không tìm thấy file" hàng loạt thì nghi shell trước. (nguồn: JudgeHub, SAB-Store)
- Heredoc qua Bash tool nuốt một cấp backslash (kể cả `<<'EOF'`) và có trần ~7 KB (vượt thì `unexpected EOF`, không file nào được ghi) → nội dung có backslash/dài/nhiều backtick dùng Write tool, đọc lại đúng dòng; ký tự vô hình (U+00AD, U+200B) viết dạng escape kèm comment; commit nhiều dòng `git commit -F <file>`. (nguồn: attendance-hcmus)
- Hook scout-block chặn MỌI lệnh Bash có chuỗi `node_modules` hoặc `build` (kể cả trong heredoc/chuỗi Python) → Write tool hoặc đặt script vào scratchpad rồi chạy; không sửa `.ckignore` khi user chưa yêu cầu. Serena `get_diagnostics_for_file` chỉ là tsc — không có luật typed-lint (`no-unsafe-*`, `no-unnecessary-type-assertion`) → `npx eslint <file> --max-warnings 0` cho MỌI file đã đụng kể cả test (`eslint .` toàn repo hay vượt trần tool); nguồn `any` hay gặp là mock Prisma — giữ tham chiếu mảng truyền vào mock, không `eslint-disable`. (nguồn: SAB-Store, attendance-hcmus, JudgeHub)
- `get_impact_radius_tool` trên node trung tâm có thể vượt trần token → thu hẹp depth hoặc dùng `get_minimal_context_tool`. serena / code-review-graph không phủ file untracked (đã có ở `mem:lessons/tooling`); index rỗng thì build lại. (nguồn: JudgeHub)
- Script vận hành đọc kết quả bằng `git log -1`/đuôi log, không bằng exit code; log docker build đọc bằng `grep -iE "failed|error|Built"` (không `| tail -3`). Chỉ tin phép đo A/B xen kẽ; `git grep -E` không hiểu `\s` (dùng `[[:space:]]`). (nguồn: JudgeHub, attendance-hcmus)
