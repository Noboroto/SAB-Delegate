# Next.js + AntD — cạm bẫy đã đo

- Next 16: `proxy.ts` thay `middleware.ts`; có CẢ HAI → server crash lúc khởi động ("Both middleware file and proxy file are detected"), báo Unhandled Rejection rồi trả 404 cho MỌI route trong khi cổng vẫn mở (trông như lỗi routing). Logic chặn request (cookie locale next-intl, redirect đăng nhập) chỉ ở `apps/web/proxy.ts`; kiểm version Next ở `package.json`. Proxy chỉ redirect lạc quan, KHÔNG phải nơi kiểm quyền. (nguồn: JudgeHub, Leaderboard, QR-Production-Manager, attendance-hcmus, ComparableTransaction)
- Thành viên ghép của AntD (`Skeleton.Input`, `Skeleton.Button`, `Typography.Title`, `Radio.Group`) trong server component (`loading.tsx`) đọc ra `undefined` (client reference chỉ phơi named export): "Element type is invalid" bị boundary nuốt → response vẫn 200, vitest `renderToString` vẫn xanh; đo 118 lần/4 giờ trên prod từ MỘT `loading.tsx`. **How**: file dùng thành viên ghép phải `'use client'` hoặc import named; guard test `antd-compound-needs-client` quét repo; chẩn đoán bằng log container, không access log. (nguồn: JudgeHub)
- API tĩnh của AntD (`Modal.confirm`, `message.*`, `notification.*`) render ngoài `<ConfigProvider>` → nền trắng trên app dark, bỏ qua theme/i18n (4 vòng review + hàng nghìn test + live-verify chỉ light đều lọt). **How**: `App.useApp()` ở mọi chỗ với `<App>` bọc trong ConfigProvider; lint `no-restricted-syntax`/`no-restricted-imports` cấm API tĩnh; test bọc `<App>`; live-verify cả light/dark và vi/en. (nguồn: attendance-hcmus, JudgeHub)
- Token theme: `controlHeight`/`controlHeightSM` của AntD ConfigProvider đồng bộ với `--control-h` (32 px)/`--control-h-sm` (24 px) trong CSS tokens; không hardcode `height`, không trộn `size="small"` với mặc định trong một hàng; nút tự viết dùng `var(--control-h)`. Màu chỉ qua token, không mã màu rời; màu trạng thái đạt WCAG AA sáng/tối. Audit lặp lại: scanner Playwright tìm flex-row có con khác chiều cao > 3 px. (nguồn: JudgeHub, Leaderboard, attendance-hcmus)
- Route động: redirect thật là `redirects()` 308 trong `next.config` (giữ query string) — page-stub `redirect()`/`permanentRedirect` trả HTTP 200 + RSC nên crawler (facebookexternalhit, Zalo) dừng ở vỏ 200. Preview hiện tên app chung là do THIẾU `generateMetadata` (không phải rate-limit, redirect login hay `loading.tsx`); Facebook/Zalo cache preview theo URL. Đổi route khi chưa có người dùng thì xoá hẳn không alias. (nguồn: Leaderboard, QR-Production-Manager, JudgeHub)
- Markdown do admin soạn (embed description, welcome message) hiển thị qua đúng MỘT renderer, màn soạn preview bằng chính renderer đó; KHÔNG `rehype-raw`/`dangerouslySetInnerHTML` (stored XSS); mở rộng bằng remark-gfm/directive map sang component; Discord markdown đi qua remark an toàn. (nguồn: JudgeHub, attendance-hcmus)
- `NextIntlClientProvider` nhận cả object messages: chia file locale theo vùng/route KHÔNG giảm payload (162 KB trong document 347 KB ≈ 30 KB gzip, 1,7% page weight) — chỉ giải quyết xung đột merge. Tối ưu thật hơn: font khai báo hai lần (`localFont` + `next/font/google`) = 332 KB (19% trang), thu hồi ≥ 105 KB → khai font MỘT lần. `viewAs`-like đổi vai trò phải `router.refresh()`. (nguồn: JudgeHub)
- Tìm kiếm tài liệu hiện hành (context7) cho AntD/next-intl/Better Auth/Necord kể cả thứ tưởng đã thuộc; chuẩn a11y tra WAI-ARIA APG. Build `next build` thật + Playwright sau deploy, không chỉ curl 200. (nguồn: JudgeHub, laptop-shortlist)
- Mở site cần Chrome thật (Discord Developer Portal, Coolify) bằng connector, không Playwright (xem `mem:lessons/testing/browser-e2e-verify`); đổi dependency Next/AntD: kiểm `npm view <pkg> version` thật cho mọi dependency trực tiếp (audit/`pnpm outdated` bỏ sót Next 16.2.9 → 16.3.x vá RCE `/_next/image`). (nguồn: Leaderboard)
