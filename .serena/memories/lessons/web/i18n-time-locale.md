# i18n vi/en, chính tả, múi giờ (apps/web + messages dùng chung)

- Mọi chuỗi qua i18n, đủ cả `vi` và `en`; server trả MÃ lỗi (`ErrorCode`), web dịch. Test parity `locale-parity`: cùng key path vi/en, không namespace khai ở 2 file (object-spread trùng bị nuốt, last-wins), cùng tập file, mọi namespace qua barrel; test import barrel không import `.json` thô. Mock `t()` trả lại key KHÔNG chứng minh có bản dịch → test đọc FILE LOCALE THẬT, danh sách key dẫn từ schema/enum chứ không liệt kê tay; component gọi hook next-intl bọc provider trong test. (nguồn: JudgeHub, openproject-docker, attendance-hcmus)
- Chính tả tiếng Việt thống nhất kiểu oá/oè/uỷ: Xoá, khoá, Huỷ, hoà, thoả, tuỳ; cấm Xóa/khóa/Hủy/hóa/thóa/tùy trong UI, `messages/vi.json`, docs và chuỗi Discord reply nếu cùng quy ước. **How**: grep guard trên `messages/vi.json` chặn `Xóa|khóa|Hủy|hóa|thóa|tùy`. (nguồn: JudgeHub, attendance-hcmus)
- Ngày giờ: DB `timestamptz`, mọi chuỗi ngày/giờ hiển thị đi qua MỘT formatter có `timeZone` cố định (không `toLocale*` trần, không `dayjs().format` theo trình duyệt; ESLint chặn `toLocale*`, `getTimezoneOffset`, getter/setter giờ địa phương ngoài module đó); picker/filter làm việc theo múi giờ nghiệp vụ; thời điểm sự kiện = `now()` server. Test chạy dưới `TZ=UTC` và `TZ=Asia/Ho_Chi_Minh`. Giờ hiển thị theo timezone của guild/ứng dụng, không theo máy người xem. (nguồn: attendance-hcmus, Leaderboard, QR-Production-Manager, JudgeHub)
- Bot dùng `use-intl/core` `createTranslator` + cùng `messages/{vi,en}.json` với web; mô tả lệnh qua `setDescriptionLocalizations`, tên lệnh giữ nguyên; kiểm chuỗi vi dài làm tràn UI/embed khi live-verify cả hai locale. (nguồn: Leaderboard, JudgeHub)
