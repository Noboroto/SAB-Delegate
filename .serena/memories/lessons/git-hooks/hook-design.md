# Git hook là cổng chất lượng duy nhất (không CI)

- Hook phải thực sự chạy: hook mode 100644 hoặc `core.fileMode=false` → git chỉ in `hint: ... hook was ignored because it's not set as executable` và bỏ qua mọi cổng; `core.hooksPath` rỗng/trỏ chỗ khác cũng tắt cổng. **How**: index 100755 (`git update-index --chmod=+x`); script `prepare` chạy husky + chmod + stat lại, exit 1 nếu fail; thấy hint → `pnpm install`, không commit tiếp; đo lại `core.hooksPath` mỗi máy. (nguồn: ComparableTransaction, data-tuyensinh, SAB-Store)
- Husky gọi hook bằng `sh -e` (bỏ qua shebang) và `/bin/sh` macOS là bash 3.2 → cần `require-bash.sh` re-exec sang bash ≥ 4; kiểm bằng `PATH=/usr/bin:/bin sh -e .husky/<hook>`. `pre-push` đọc danh sách ref từ stdin MỘT lần → script chạy lại dưới khoá phải nhận ref qua biến môi trường. `.husky/_/` tự gitignore. (nguồn: SAB-Store)
- Thứ tự pre-commit: prettier → eslint (`--max-warnings 0`) → typecheck → knip → vitest. **Why**: knip chạy cuối sau full suite làm 6 commit qua pre-commit rồi đỏ ở pre-push vì 1 `export function` thừa (~30 phút). **How**: knip đầy đủ chạy TRƯỚC mọi vitest, cả pre-commit khi có code/manifest; commit CHỈ thêm dependency FAIL knip → dependency nằm cùng commit với code dùng nó. (nguồn: Leaderboard, SAB-Store)
- Hook phân loại theo phạm vi thay đổi: trần số file staged (29, chặn cứng — tách commit theo module/feature), trần dòng/file (spec dài tách `<name>.test-harness.ts`), commit chỉ `.md`/hook/compose không chạy gì (nhưng index còn file cũ vẫn chạy ESLint toàn repo → kiểm `git diff --cached --name-only`), file test staged chạy trực tiếp, gốc workspace/shared → full suite. `vitest related` không theo `require()` nên bỏ sót. Số ngưỡng ghi trong hook, không chép vào AGENTS.md. (nguồn: Leaderboard, SAB-Store, QR-Production-Manager)
- Hook test WORKING TREE chứ không phải nội dung staged (pre-push cũng vậy): sửa dở của agent làm push sạch bị đỏ, `git add -p` không được chứng minh. **How**: chỉ commit/push khi không agent nào đang sửa dở; guard chỉ quét file tracked → trước chuỗi commit dùng `git add -N`; sau chuỗi lỗi `git reset -q` vì nhóm lỗi vẫn staged. (nguồn: Leaderboard, QR-Production-Manager, ComparableTransaction)
- Không chạy lint/test/typecheck "lần cuối" ngay trước commit (hook đã chạy đúng bộ đó → gấp đôi thời gian); vẫn chạy test hẹp trong TDD và khi chẩn đoán hook đỏ. Trước CHUỖI commit nhóm, chạy MỘT lần mọi thứ hook sẽ chạy. Lint rẻ nên chạy sớm trên file đã đụng (`npx eslint <file>`). (nguồn: JudgeHub, Leaderboard, QR-Production-Manager)
- `git commit/push` qua hook có thể vượt trần 10 phút của Bash tool (exit 143; `run_in_background` cùng trần nên có lúc bị kill). **How**: chạy background-run ghi output ra file, đọc đuôi (`tail -20`; hook in khối lỗi cô đọng ở cuối, log đầy đủ ở `.git/hook-logs/` — nằm dưới `.git` nên không đồng bộ lung tung); bị kill thì chạy detached (`nohup ... &`) rồi poll file. Hook "Hook timed out in 10000ms" ở beforeAll thường là flaky do tranh CPU → `hookTimeout: 30_000`, không bypass. (nguồn: JudgeHub, Leaderboard)
- `TEST_REQUIRE_DB=1` export trong pre-commit/pre-push: spec cần Postgres mà không kết nối được phải FAIL, không tự skip (helper `require-db`; guard `no-skipped-db-specs`). Commit chạm server cần Postgres dev đang chạy vì hook chạy `migrate deploy` trên DB test. (nguồn: Leaderboard, QR-Production-Manager)
- Guard "ratchet" (đếm tổng offender toàn repo so với trần) làm mọi thêm vi phạm là đỏ, kể cả trong test. **How**: ghi thẳng vào prompt giao việc ("không `export interface`; type tham số suy từ schema shared bằng `Pick<>`") và bắt agent chạy guard test khi verify; wave đổi type/export/Zod/eslint-disable thì verify chạy `pnpm --filter <pkg> test guard` kèm test hẹp. (nguồn: JudgeHub)
- `commit-msg` hook chặn chuỗi AI (claude/anthropic/codex/chatgpt, không phân biệt hoa/thường, trừ tên `CLAUDE.md`) và trailer `Co-Authored-By`/"Generated with"; chọn quyết định chủ repo: commit SAB-Delegate KHÔNG có dòng attribution AI → hook này chấp nhận được và thắng gợi ý trailer của harness. **Why**: trailer harness làm commit chết SAU KHI pre-commit đã chạy ~10 phút (24/09/2026). **How**: grep message trước khi `git commit`; ba gate commit message ở ba nơi khác nhau, `find -maxdepth 3` không chứng minh vắng mặt. (nguồn: JudgeHub, Leaderboard, QR-Production-Manager, SAB-Store, ComparableTransaction)
- Nhiều phiên chung một working tree: `git status -sb` trước mỗi commit; commit lạc nhánh thì `git push` vẫn báo "up-to-date" → đối chiếu `git ls-remote origin <branch>` với HEAD; cherry-pick sang nhánh đích, so `git patch-id --stable`, không `reset --hard` nhánh phiên khác. Xoá/đổi tên file lúc phiên khác chạy `eslint .` toàn repo làm commit của họ đỏ `ENOENT` → báo trước. Không `git worktree` để tách. (nguồn: JudgeHub)
