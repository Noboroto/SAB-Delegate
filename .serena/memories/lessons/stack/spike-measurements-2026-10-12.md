# Số đo spike W0 (12/10/2026) — chi tiết trong `docs/stack-decisions.md`

- Necord 7 + Nest 12 là ESM-only nhưng app CJS (`nodenext`) chạy được qua `require(esm)` trên Node 24; MCP SDK có bản `.cjs`. pnpm 12 bỏ qua field `pnpm` trong package.json → `peerDependencyRules` (necord vs discord-api-types 0.38) + `allowBuilds: { necord: false }` phải nằm ở `pnpm-workspace.yaml`, thiếu thì `ERR_PNPM_IGNORED_BUILDS`.
- Dưới CJS, kiểu `AutocompleteInteraction` import từ discord.js khác kiểu Necord thấy (TS2416) → suy kiểu từ `Parameters<AutocompleteInterceptor['transformOptions']>[0]`.
- `editMe({nick, avatar})`: đổi avatar lần 2 sau ~60 s → `400 / 50035 AVATAR_RATE_LIMIT` (không phải 429, không retry-after), CẢ request bị từ chối (nick cũng không đổi) → gửi nick và avatar thành 2 request. Bulk PUT guild commands: bucket 2 lần/30 s.
- Necord `development: [...]` ghi đè `guilds` của mọi lệnh kể cả khi `skipRegistration` → prod `development: false`.
- Prisma 7.10 + adapter-pg: thiếu `options: '-c timezone=UTC'` ở pool thì `timestamptz` lệch 7 giờ khi session không UTC; có option thì không cần patch adapter. `prisma` dist-tag `latest` = 8.0 rc → ghim 7.10.0. Zod sinh từ Prisma không mang CHECK (tháng 13 lọt) → wrapper tay trong shared.
- pg-boss 12: không thư viện nào đảm bảo thứ tự tắt; luật đo được: pg-boss stop trong `onModuleDestroy`, Prisma/Necord đóng trong `onApplicationShutdown` (đóng pool ở `onModuleDestroy` làm job đang chạy hỏng). Thiếu listener `error` → Postgres restart giết tiến trình. `missed:'once'` tạo đúng 1 job bù; `cancel(name, id)`. `@wavezync/nestjs-pgboss` start trong `compile()` → tự viết facade.
- MCP SDK v2 stateless trên Fastify: hook Origin phải khớp `request.routeOptions.url` (URL thô bị vượt bằng `/%6dcp`); sau `reply.hijack()` header helmet/`onSend` mất (chỉ `reply.raw.setHeader` còn); `verifyBearerToken` từ chối token không có `expiresAt`.
- Better Auth 1.7.7 stateless: `input:false` làm `mapProfileToUser` bỏ field âm thầm; Origin check tắt khi `NODE_ENV=test` → đặt `advanced.disableOriginCheck:false`; access token nằm trong cookie `account_data`, đọc bằng `getAccessToken({ body: { useAccountCookie: true } })`; Fastify phải chuyển nhiều `Set-Cookie` bằng `getSetCookie()`. Đăng nhập thật CHƯA đo (W7).
