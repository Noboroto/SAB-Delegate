# Secret, log, transcript

- Kiểm env container trên server CHỈ in TÊN biến: `docker inspect ... --format '{{range .Config.Env}}{{println .}}{{end}}' | cut -d= -f1 | grep -i <pat>`. Không tin regex che: 10/10/2026 một lệnh `sed` che chỉ dạng URI `user:pass@`, còn `*_PASSWORD=...`/`*_KEY=...` lọt vào transcript → phải rotate. Coolify tiêm MỌI env của compose vào MỌI service của resource → secret xuất hiện ở container không liên quan; chỉ khai token bot cho resource thực sự cần. (nguồn: coolify)
- Không in `docker compose config` đã nội suy (in giá trị secret thật; 26/09 phải rotate) → dùng `config --no-interpolate` hoặc `config -q`; không tái dùng config đã render; không `source` file secret (`TOKEN=7|abc...` không quote làm zsh coi `|` là pipe và in phần token trong lỗi → revoke). Đọc bằng `cut -d= -f2- file | tr -d "'"` và đưa qua stdin (không argv); lưu giá trị trong dấu nháy đơn. File credential không có dòng tiêu đề làm bộ lọc "che cột pass*" bỏ sót (12 tài khoản phải rotate) → chỉ `cut -f1`. Lộ bí mật → rotate/revoke NGAY rồi báo user. (nguồn: Leaderboard, QR-Production-Manager, SAB-Store)
- Không ghi secret/.env/token vào repo, plan, report, memory — chỉ TÊN biến (repo và `.serena` được Syncthing đồng bộ giữa máy); `.env.example` liệt kê tên. Quy trình rotate token bot Discord khi lộ; token không bao giờ qua argv/transcript; secret sinh ngay trên host (`openssl rand`), mode 600. (nguồn: coolify, Leaderboard)
- Coolify bơm secret thành `--build-arg` ở mọi stage → ghi vào `docker history`: `is_buildtime=false` ngay khi tạo biến; sau deploy `docker history --no-trunc <image> | grep -c 'SECRET='` = 0 (chi tiết ở `mem:lessons/deploy/coolify-compose-lifecycle`). Sửa env Coolify qua tinker: truyền `docker exec -e KEY` không kèm giá trị, chỉ in độ dài/`is_buildtime`. (nguồn: SAB-Store)
- Log: pino `redact.paths` không hiểu `**` (xem `mem:lessons/nestjs/http-and-runtime`); log tên key/id, không log giá trị nghiệp vụ; không ghi token thô khi chẩn đoán JWT; import/export DB không bao giờ ghi/xuất credential. (nguồn: JudgeHub, QR-Production-Manager, ComparableTransaction)
- Secret scanner (GitGuardian) báo fixture token giả: `.gitguardian.yaml` `version: 2`, `secret.ignored_paths` liệt kê ĐÚNG file fixture, không bỏ cả cây test; mật khẩu test sinh lúc chạy (`fixturePassword`/`fixtureSecret`). Incident cũ do user tự đóng trên dashboard. (nguồn: Leaderboard, attendance-hcmus)
- Playwright MCP echo giá trị gõ → không đưa secret vào call (xem `mem:lessons/testing/browser-e2e-verify`). Lệnh ghi đè cả file bằng redirect trên file gitignored (`sed -n ... > f`) mất vĩnh viễn vì không có lịch sử → `cp` trước hoặc dùng Edit. (nguồn: ComparableTransaction, attendance-hcmus)
- Markdown/nội dung do admin soạn không render raw HTML (stored XSS); mọi cổng quyền ở guard server (xem `mem:lessons/nestjs/di-and-build`). (nguồn: JudgeHub)
