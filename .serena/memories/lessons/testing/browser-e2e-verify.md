# Verify trình duyệt (Playwright MCP / chrome connector)

- Browser/E2E/live-verify BẮT BUỘC qua MCP (Playwright MCP; chrome-devtools/claude-in-chrome khi cần phiên Chrome thật); cấm cài hoặc tự viết script `playwright`/`puppeteer`. Trang cần phiên đăng nhập thật (Discord Developer Portal, dashboard Coolify, prod SSO) → chrome connector, vì Playwright MCP bị đá về /login; Discord OAuth thật không tự động hoá được bằng Playwright thuần. Localhost/preview + tài khoản test → Playwright MCP. Khi giao subagent phải nói rõ dùng connector nào. (nguồn: JudgeHub, attendance-hcmus, Leaderboard, QR-Production-Manager)
- Playwright MCP ECHO lại mọi code/giá trị gõ: không bao giờ đưa mật khẩu/token vào call, không snapshot trang khi ô mật khẩu có giá trị. **How**: user `*.test` throwaway mật khẩu ngẫu nhiên, ghi file chmod 600, phục vụ MỘT lần qua server loopback rồi `ctx.request.post(sign-in)` (cookie dùng chung với page); xoá user + row E2E trong DB dev ngay; xoá `.playwright-mcp/` sau. Cho web SAB: seed session Better Auth thay vì đăng nhập Discord. (nguồn: ComparableTransaction, attendance-hcmus)
- Giới hạn công cụ: `file://` bị chặn (serve HTTP tạm rồi dừng); `browser_file_upload` chỉ nhận path trong repo + `.playwright-mcp/`; `filename` tương đối ghi vào GỐC repo (rác untracked) → luôn `filename: ".playwright-mcp/<x>"`; trang có leave-guard sinh dialog `beforeunload` native kẹt cả phiên nếu thiếu `browser_handle_dialog` (nạp cùng cụm trong MỘT ToolSearch) ; download thật đóng page MCP → chặn click `a.download`. (nguồn: JudgeHub, attendance-hcmus, ComparableTransaction)
- Thời gian: cửa sổ Playwright MCP chạy rAF ~1 fps (~1017 ms/khung) → toast AntD duration 5 s biến mất sau ~10 s; đo rAF trước khi kết luận lỗi thời gian, đo bằng timer (`setTimeout` patch/`transitionend`); toast tự tắt ~3 s → gắn MutationObserver TRƯỚC hành động; dùng `domcontentloaded` + chờ selector cụ thể (SSE/mount lười không bao giờ tới `networkidle`). (nguồn: JudgeHub, Leaderboard, attendance-hcmus)
- Selector: scope trong dialog (overlay nuốt pointer), không `getByRole('link').first()` (khớp skip-nav/logo), hash CSS-module đổi → dùng `data-testid`/role/text. Phản hồi sign-in 200 không chứng minh có phiên: assert route chỉ-khi-đăng-nhập render đúng user. Better Auth rate limit sign-in 5 lần/15 phút (bộ đếm trong tiến trình) → dùng lại `storageState`. (nguồn: attendance-hcmus, JudgeHub)
- Mỗi wave web verify trên localhost bằng Playwright MCP trước commit (unit test + hook không tính là verify): 3 kích thước (390×844, 768×1024, 1440×900) × sáng/tối × vi/en; gom vào một `browser_run_code_unsafe`. Đổi theme bằng set key lưu theme + reload (đừng bấm tay) rồi mở lại dialog/toast/popover/confirm mới thêm. Sau migrate/`prisma generate` restart dev server (client cũ trong bộ nhớ → model `undefined` → 500 không phải bug code). (nguồn: Leaderboard, attendance-hcmus, ComparableTransaction)
- jsdom/happy-dom không thấy layout sụp (slide cao 23 px, test vẫn xanh) → chụp ảnh sau khi đổi wrapper; sau deploy web mở prod bằng trình duyệt, kiểm có dữ liệu + console sạch (một khoá sai làm bảng TRẮNG trên prod trong khi mọi cổng qua và curl 200). Đọc log Grafana/prod bằng HTTP API thay vì render UI (render dashboard làm treo renderer CDP 45 s). (nguồn: ComparableTransaction, laptop-shortlist, JudgeHub)
- Verify bằng browser là việc nặng: giữ khoá, xác nhận không có gì nặng khác toàn máy, chỉ dựng thứ cần và tắt sau; MCP xác thực tương tác có thể vắng trong phiên headless/cron; subagent loại thiếu `mcp__playwright__*` trả BLOCKED. (nguồn: JudgeHub, Leaderboard)
