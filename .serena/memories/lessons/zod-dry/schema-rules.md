# Zod là nguồn sự thật duy nhất (packages/shared)

- Chuỗi nguồn: `schema.prisma` → migration → Zod sinh từ Prisma (`prisma-zod-generator`) → mọi DTO/enum dẫn xuất bằng `.pick/.omit/.extend/.partial` + `z.infer`. Cấm hand-write Zod cho model DB và cấm `export interface`/`export type` cho dữ liệu request/response (guard test; whitelist theo từng field có lý do; hai ngoại lệ: augment type third-party, utility type không có Zod tương đương). Schema/enum/hằng dùng ≥ 2 file đặt MỘT chỗ trong `packages/shared` (giới hạn Discord 2000 ký tự, role, trạng thái, ngưỡng); không chép literal vào prose/code khác. **Why**: hai nguồn drift âm thầm. **How**: 3 guard test (`strict-usage`, `no-export-interface`, `no-duplicate-db-enum`) trong shared, chạy ở hook; kiểm DRY khi thêm type: dùng ở ≥ 2 package? shape DB? response DTO? (nguồn: JudgeHub, Leaderboard, QR-Production-Manager, attendance-hcmus, ComparableTransaction)
- Field thừa = STRIP (mặc định); cấm `.strict()/.passthrough()/.loose()/.strictObject/.looseObject/.catchall()`: strict giòn khi server thêm field, passthrough rò dữ liệu chưa validate. Muốn khoá shape thì assert `.shape` trong test. Envelope danh sách giữ key anh em (`pagination`) vì strip làm rơi chúng; required = không `.optional()` không `.default()`. `string` luôn `trim()` (trừ mật khẩu), email lowercase; `z.iso.datetime()` thay `z.date()`. (nguồn: JudgeHub, Leaderboard, QR-Production-Manager, ComparableTransaction, attendance-hcmus)
- `.partial()` GIỮ `.default()`: PATCH `{status}` parse "không gửi" thành default (`[]`) → xoá sạch 100 item (`problemCount` 100 → 0) không báo lỗi. **How**: helper `partialWithoutDefaults` (hoặc redeclare field không default) cho mọi `UpdateXSchema` (PATCH cấu hình guild); test "gửi một field không đổi field khác"; đọc lại sau PATCH để xác nhận. (nguồn: JudgeHub)
- `.omit()` là allow-by-default: cột mới thêm vào Prisma tự vào DTO → rò nếu nhạy cảm; dùng `.pick()` (allow-list) cho response hoặc omit tường minh cột nhạy cảm. Zod parse để tin KIỂU, không để chặn RÒ (xem `mem:lessons/postgres-prisma/query-safety`). (nguồn: QR-Production-Manager, JudgeHub)
- Dữ liệu đọc từ DB parse bằng Zod ở biên service → controller, không cast: type Prisma chỉ ở tầng type, cột JSONB/Json là `any` runtime, dữ liệu cũ/seed/import/sửa tay lệch shape. Áp cho mọi cột Json (cấu hình guild, poll, schedule, embed template). (nguồn: JudgeHub, data-tuyensinh, attendance-hcmus)
- Sau `prisma generate` phải build `packages/shared` rồi mới typecheck/test; shared dùng từ bản build thì build cũ = xanh giả (sửa message trong shared không build lại → test server xanh với text cũ). **How**: `pretest`/`predev`/`prebuild` build shared (hoặc trỏ `exports` tới source); consumer KHÔNG `import 'zod'` mà lấy `z` từ shared để một instance mang `z.config` (customError tiếng Việt); không `sideEffects:false` cho shared vì `z.config` là side effect; dev: `build:watch`. (nguồn: SAB-Store, JudgeHub)
- Mọi list API dùng MỘT prototype query (page, pageSize, sort, filter theo cột) parse từ URL bằng `z.coerce`, sort key qua allowlist; web AntD Table đọc/ghi URL state cùng prototype. Số nguyên của body không dùng `z.coerce`. (nguồn: attendance-hcmus, ComparableTransaction)
- Ràng buộc giá trị ở Zod (`.refine()` trong shared / guard test), SQL chỉ giữ unique/FK/index theo mô hình JudgeHub/QR; ngược lại SAB-Store/attendance chấp nhận CHECK/partial index là lớp fail-closed trùng Zod — chưa chốt cho SAB-Delegate (xem conflicts). (nguồn: QR-Production-Manager, JudgeHub, attendance-hcmus)
- Schema không đổi giá trị đã lưu: union type cho action/audit (vd 9 action giữ chuỗi gốc `PLUGIN.UPDATE` dù key SCREAMING_SNAKE; "dọn cho đẹp" = bỏ rơi 68.790 hàng), hàm bọc nhận union không phải `string`, guard neo call site. (nguồn: JudgeHub)
- Golden fixtures + `ErrorCode` (xem `mem:lessons/testing/nest-and-db-tests`, `mem:lessons/nestjs/di-and-build`) khi chuyển validation giữa các stack. (nguồn: SAB-Store)
