- Necord 7 `@Options()` builds the object with `interaction.options.getX(name, required)`: an optional option the person left EMPTY arrives as `null`, not `undefined`.   - Fix (172adff): command code imports `Options` from `apps/server/src/discord/decorators/options.decorator.ts` (Necord Options + first pipe `OmitEmptyOptionsPipe` dropping null keys). A spec guard fails if any file imports `Options`/`Opts` from 'necord'. Nest param pipes DO run in Necord contexts (ExternalContextCreator always applies them); Necord's enhancer (option metadata for registration) still runs when the first arg is a pipe.
